É um sistema interativo desenvolvido para calcular o consumo mensal de energia elétrica de aparelhos domésticos. 
O seu principal objetivo é permitir que o usuário estime o gasto financeiro na conta de luz a partir da potência do equipamento e de suas horas de uso. promovendo um consumo mais consciente.


Linguagem: Python 3.x


O sistema calcula o consumo mensal em Quilowatt-hora (kWh) utilizando a seguinte equação física: $Consumo = \frac{Potência \times Tempo \times Dias}{1000}$
Onde:Potência é informada em Watts (W).
Tempo é a quantidade de horas que o aparelho fica ligado por dia.
Dias é a quantidade de dias de uso no mês.
Para calcular o impacto na conta de luz, o sistema aplica: $Custo = Consumo \times Tarifa$
